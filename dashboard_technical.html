How to read this dashboard
  • Every time the API is used, it is recorded here: calls to /score, /demo, /health and so on. Opening this page does not count.
  • The model gives each transaction a fraud score (its estimated chance of fraud) and decides APPROVE or REVIEW. A transaction goes to REVIEW when its score is above €5 ÷ (€5 + amount), so expensive transactions are checked at much lower scores than small ones.
  • Test traffic is not like real traffic. The “Send 50 test transactions” button and /demo use samples that contain far more fraud (about 18% and 40%) than real card traffic (about 0.2%). Their alert rates and scores look high on purpose. Choose Show → Real API calls only to hide them.
  • Drift asks whether recent inputs look like the training data. The two time-of-day features always change when traffic covers only part of the day, so they are shown but not counted as problems.
